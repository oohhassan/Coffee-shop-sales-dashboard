# Coffee Shop Sales Dashboard

I built this dashboard in Microsoft Excel to explore coffee shop sales and practise turning transaction data into a clear visual summary. The project looks at revenue over time and how transaction activity varies by weekday, hour and product category.

## Questions explored

- How does revenue change from month to month?
- Which days of the week have the most transactions?
- What are the busiest hours of the day?
- How do transaction counts compare across product categories?

## What's included

The **Coffee Shop Sales.xlsx** workbook contains two sheets:

| Sheet | Contents |
| --- | --- |
| Dashboard | PivotTables and four charts summarising monthly revenue and transactions by weekday, hour and product category. |
| coffee shop sales | Transaction data with store locations, products, quantities, prices and additional fields used for analysis. |

The dataset includes transaction dates and times, store and product identifiers, product categories, product details, quantities and unit prices. Additional columns include revenue, month, weekday and hour.

## Tools and techniques

- Microsoft Excel
- PivotTables
- Charts for comparing sales patterns
- Date and time fields for grouping transactions
- Revenue calculated from quantity and unit price

## How to view the project

1. Download **Coffee Shop Sales.xlsx** from this repository.
2. Open it in Microsoft Excel.
3. Start with the **Dashboard** sheet to explore the charts.
4. Open **coffee shop sales** to inspect the underlying data.

The workbook contains both the dataset and the dashboard, so no separate data download is needed.

## About this project

This is a portfolio project demonstrating my Excel analysis and dashboard skills. The charts describe sales activity; they do not measure profitability because the listed data does not include operating costs.
